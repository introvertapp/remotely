## Downloads

Prebuilt remotely apps are now available for macOS 14 Sonoma and later. No Xcode,
Swift installation, or source build is needed.

| Mac | Recommended download | ZIP alternative |
| --- | --- | --- |
| Apple Silicon (M1 or later) | `remotely-1.3.1-macos-arm64.dmg` | `remotely-1.3.1-macos-arm64.zip` |
| Intel | `remotely-1.3.1-macos-x86_64.dmg` | `remotely-1.3.1-macos-x86_64.zip` |

Open the DMG and drag remotely into Applications, then eject the disk image and
open remotely. These are two separate native builds.

## First launch

These builds are ad-hoc signed, with no Apple Developer ID or notarization.
After attempting to open remotely, use **System Settings → Privacy & Security →
Open Anyway** if macOS blocks the first launch. Allow local-network access if
asked, then use remotely's menu-bar icon to open Preferences and pair an Apple TV.
See [Apple's instructions](https://support.apple.com/102445).

## Changes

- Adds separate Apple Silicon and Intel DMG and ZIP downloads.
- Pins dependency resolution and includes third-party notices, license texts,
  and dependency privacy resources inside each app.
- Adds artifact checks, SHA-256 checksums, and build provenance.
- Keeps the existing remote, MiniRemote, Now Playing, app launcher, keyboard
  input, preferences, and pairing credential namespace.

## Updating

Quit remotely before replacing the app in Applications. macOS may request
Keychain access again because these builds use ad-hoc signatures. If a saved
pairing cannot be used, remove that pairing in Preferences and pair again.
There is no automatic updater.

`SHA256SUMS` covers all four downloads, `BUILD_INFO.txt`, and `INSTALL.txt`.
Run `shasum -a 256 -c SHA256SUMS` in a directory containing those files to check them.
